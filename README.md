# Exercices techniques — candidature stage

Deux exercices courts, à faire avant l'entretien technique. Compte **4 à 6 heures en tout**, pas plus.

| Dossier | Sujet | Stack |
|---|---|---|
| [`exercice-1/`](exercice-1) | Réparer une application React qui contient 5 bugs | React + Vite |
| [`exercice-2/`](exercice-2) | Construire une petite API de signalement de bugs | Node.js + Express + base de données |

Chaque dossier contient **l'énoncé complet en PDF** et les documents dont tu as besoin pour démarrer.
Lis le PDF en premier : il contient les consignes détaillées et les critères d'évaluation.

## Comment rendre ton travail

Tu ne pousses **rien** sur ce dépôt-ci : il est en lecture seule pour toi.

1. Crée **ton propre dépôt GitHub** (un par exercice, ou un seul avec deux dossiers).
2. Copie dedans le contenu de départ fourni ici.
3. Travaille **sur une branche**, jamais directement sur `main`.
4. Quand tu as fini, ouvre une **Pull Request** de ta branche vers ton `main`, décris ce que tu as fait — et **ne la merge pas**.
5. Envoie-moi les liens des Pull Requests.

## Ce que je regarde

Ce n'est pas « est-ce que ça marche à la fin ». C'est **comment tu raisonnes pour y arriver**.
Un exercice à moitié fini mais bien expliqué vaut mieux qu'un exercice fini que tu ne sais pas justifier.

Si un point te bloque plus d'une heure : note-le, passe à la suite, et écris-moi.
Demander de l'aide au bon moment fait partie du métier — ce n'est pas un mauvais point.

## Utilisation de l'IA

Autorisée. Mais tu dois pouvoir m'expliquer **chaque ligne** que tu rends : je poserai des questions précises dessus.
