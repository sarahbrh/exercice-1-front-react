# Exercices techniques — Saint-Laurent IT Solutions

Exercices remis dans le cadre d'une candidature de stage.
Lis le PDF de chaque dossier en premier : il contient les consignes détaillées et les critères d'évaluation.

## Les deux exercices qui comptent

Compte **4 à 6 heures en tout**, pas plus.

| Dossier | Sujet | Stack |
|---|---|---|
| [`exercice-1/`](exercice-1) | Réparer une application React qui contient 5 bugs | React + Vite |
| [`exercice-2/`](exercice-2) | Construire une petite API de signalement de bugs | Node.js + Express + base de données |

## Les deux exercices bonus

**Facultatifs.** À n'ouvrir que si les exercices 1 et 2 sont terminés et rendus. Aucune date imposée.

| Dossier | Sujet | Particularité |
|---|---|---|
| [`exercice-3/`](exercice-3) | Brancher le front de l'exercice 1 sur l'API de l'exercice 2 | Repart de tes deux rendus |
| [`exercice-4/`](exercice-4) | Traiter une vraie demande client | **Aucun code** — 1 heure |

## Comment rendre ton travail

Tu ne pousses **rien** sur ce dépôt-ci : il est en lecture seule pour toi.

1. Crée **ton propre dépôt GitHub** (un par exercice, ou un seul avec un dossier par exercice).
2. Copie dedans le contenu de départ fourni ici.
3. Travaille **sur une branche**, jamais directement sur `main`.
4. Quand tu as fini, ouvre une **Pull Request** de ta branche vers ton `main`, décris ce que tu as
   fait — et **ne la merge pas**.
5. Envoie les liens des Pull Requests.

*(L'exercice 4 fait exception : c'est un seul fichier Markdown, sans dépôt ni Pull Request.)*

## Ce que nous regardons

Ce n'est pas « est-ce que ça marche à la fin ». C'est **comment tu raisonnes pour y arriver**.
Un exercice à moitié fini mais bien expliqué vaut mieux qu'un exercice fini que tu ne sais pas justifier.

Si un point te bloque plus d'une heure : note-le, passe à la suite, et écris-nous.
Demander de l'aide au bon moment fait partie du métier — ce n'est pas un mauvais point.

## Utilisation de l'IA

Autorisée. Mais tu dois pouvoir expliquer **chaque ligne** que tu rends : des questions précises
seront posées dessus.
